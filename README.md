# Retail Banking & Fraud Analytics — Advanced SQL Portfolio Project

Комплексный проект по продвинутому **SQL (PostgreSQL 17)** на базе предметной области розничного банкинга и антифрод-мониторинга (по структуре классических банковских транзакционных датасетов Kaggle).

##  Бизнес-задача
Финансовая организация обрабатывает тысячи карточных транзакций ежедневно. Аналитикам и команде безопасности необходимо:
1. Выявлять подозрительные операции в режиме реального времени (аномальные всплески сумм, быстрые переводы в разных городах — *Impossible Travel*, серийные списания).
2. Оценивать удержание клиентов (*Cohort Retention*) и строить воронки активности.
3. Рассчитывать скользящие финансовые показатели (*Running Totals*, *MoM Growth*, *7-day Moving Average*) и проводить ABC/XYZ-сегментацию клиентской базы.

## Продемонстрированные навыки SQL
* **Рекурсивные CTE (`WITH RECURSIVE`):** генерация непрерывных календарных рядов для заполнения пропусков в транзакционной активности и поиск цепочек связанных переводов между счетами.
* **Продвинутые оконные функции (`Window Functions`):** `LAG` / `LEAD` для расчёта времени между транзакциями и географических скачков, `ROWS/RANGE BETWEEN` для скользящих средних, `NTILE` и `PERCENT_RANK` для квантильного анализа.
* **Когортный анализ (`Cohort Retention Matrix`):** расчёт возвращаемости клиентов по месяцам с момента первой транзакции.
* **Антифрод-правила (`Rule-Based Fraud Detection`):** выявление паттернов *Card Testing* (серия мелких списаний перед крупным) и *Velocity Checks* (превышение частоты операций за 10 минут).
* **Оптимизация запросов (`Performance Tuning`):** секционирование таблиц (`PARTITION BY RANGE`), составные и покрывающие индексы (`INCLUDE`), анализ планов выполнения (`EXPLAIN ANALYZE`).

##  Структура проекта
```text
├── README.md                  # Описание архитектуры, бизнес-кейсов и инструкция запуска
├── docker-compose.yml         # Развёртывание PostgreSQL 17 для локального тестирования
├── 01_schema_and_seed.sql     # DDL схемы БД, партиционирование и генерация реалистичных данных
├── 02_fraud_detection.sql     # Сложные SQL-запросы для поиска мошеннических паттернов
└── 03_product_analytics.sql   # Когортный анализ, LTV, MoM-динамика и ABC-сегментация
```

##  Быстрый старт
1. Запустите контейнер с **PostgreSQL 17**:
   ```bash
   docker-compose up -d
   ```
   При первом старте автоматически выполнится скрипт `01_schema_and_seed.sql`, который создаст таблицы, индексы и сгенерирует **15 000+ транзакций**, включая заложенные фрод-аномалии.
2. Подключитесь к базе (`postgres` / `postgres`, БД `banking_dwh`, порт `5432`) через DBeaver, DataGrip или `psql`:
   ```bash
   docker exec -it banking_sql_db psql -U postgres -d banking_dwh
   ```
3. Выполняйте аналитические скрипты из файлов `02_fraud_detection.sql` и `03_product_analytics.sql`.
